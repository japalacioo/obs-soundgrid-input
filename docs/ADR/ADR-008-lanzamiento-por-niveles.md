# ADR-008: Lanzamiento por niveles de evidencia

**Estado:** Aceptada · **Fecha:** 2026-11-17

Niveles:
- `core multiplataforma`: CI y simulador.
- `Waves Windows HIL`.
- `Waves macOS Intel HIL`.
- `Waves macOS Apple Silicon HIL`.

La versión 0.1.0 está solo en el primer nivel, con captura ASIO verificada contra un driver ASIO de terceros (no Waves).
